# Data

Raw videos, images and annotations are not redistributed in this repository.

Use the official VISEM-Tracking project and data release:

- <https://github.com/simulamet-host/visem-tracking>
- <https://huggingface.co/datasets/SimulaMet-HOST/VISEM-Tracking>

The reported experiments use the official 16-video training split and the held-out videos `52`, `54`, `60` and `82`, with only class 0 (normal spermatozoa).
